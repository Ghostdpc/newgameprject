# 服装效果设计（占位清单）

> 面向策划的第二版服装效果设计。占位用，正式美术资源到位前先以占位体素模型验证每件效果。

---

## 一、设计原则

| 项 | 约定 |
|----|------|
| 槽位 | 复用现有 `OutfitManager` 三骨槽：`hat_slot`(head) / `shirt_slot`(chest) / `accessory_slot`(upperarm.r) |
| 绑定方式 | 每件服装 = 外观挂件(随骨摆动) + 附带效果(穿上生效 / 脱下还原) |
| 效果来源 | 优先复用现有系统：身材缩放 / 移速 / 软糯弹簧 / 布娃娃 / 染色灰化 |
| 实现状态 | ✅ = 现有系统已支持；🔧 = 需新增小逻辑；🆕 = 需新增效果 |

## 三、暂定 / 不录入项

以下效果曾考虑，本期**不实现**：

- 🍌 香蕉手环（涂滑脚尖 / 留香蕉皮）
- 🎲 骰子挂饰（走动随机加/减时间）
- 🏋️ 哑铃（变重 / 飞扑↑移速↓）
- 🥊 拳套（飞扑命中→对方磕头）
- 🎩 魔术礼帽（随机变身体型）

## 五、接入路径

1. `items.json` 新增服装类 item（字段：`slot` / `garment: true` / `model` / `effects[]`）
2. 新增 `type` 触发器规则："on_wear 穿→apply，on_remove 脱→revert"（复用 `ItemEffect`）
3. `PlayerController` 持有"穿着槽位→item"，穿新顶旧
4. 测试场景 `outfit_demo.tscn` 扩展：一键切换 7 件服装 + 观察生效/还原
