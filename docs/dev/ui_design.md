# 游戏内 UI 设计文档

> 依据：`别抢我镜头-完整策划方案.docx`（V1.3）+ `别抢我镜头-UI交互设计文档.docx`（V1.0）
> 版本：v1.2 · 编制：2026-08-22
> 状态：设计稿，待评审后实现

---

## 1. 概述

单一普通舞台、全程同步倒计时混战、服装组件/道具/镜头位置三线并行、快门后纯系统五维评分。

游戏内 HUD 模块：

| 模块 | 触发 | 内容 |
|------|------|------|
| 倒计时 UI | 常驻 | 顶部中央全局倒计时 + 倍率徽标 |
| 相机取景 UI | 常驻 | 拍照相机 RT + 取景框贴花 + 仿相机装饰 |
| 四角玩家面板 | 常驻 | 颜色+编号+形状、服装 3 槽、道具槽 |
| 角色头顶编号 | 常驻 | 编号（遮挡时保留描边） |
| 脚底朝向光环 | 常驻 | 瓜子型贴地，指朝向 |
| 世界交互提示 | 邻近交互物 | 组件/道具图标 + 0.8s 长按进度环 |
| 头顶拾取气泡 | 捡到道具/衣服 | 飘起图标 2-3s |
| 屏幕外方位指示 | 玩家出主相机视野 | 边缘气泡 + 玩家图标指向 |
| 快门/评分/冠军演出 | 阶段触发 | 定格合照、逐维刷分、皇冠特效 |

**非分屏约束**：固定单镜头，禁止 HUD 分屏；相机遥控器只移动取景框目标，不切换场景。

## 2. 玩家辨识（三重编码）

不以颜色为唯一编码，用**颜色 + 编号 + 形状**三重辨识：

| 玩家 | 颜色 | 形状 |
|------|------|------|
| P1 | 蓝 | 圆 |
| P2 | 橙 | 三角 |
| P3 | 绿 | 方 |
| P4 | 紫 | 菱形 |

编号**永远显示**（四角面板、头顶、屏幕外气泡均带编号）。形状用于四角面板头像、屏幕外气泡、脚底光环等位置。

## 3. 倒计时 UI（顶部中央）

### 3.1 布局

屏幕顶部水平居中，对局全程显示。

```
TopBar (Control, 顶部中央)
├── TimerLabel (Label)     # 大号数字，全局唯一真值
├── RateBadge (Label)      # 倍率徽标 2.0x / 0.5x（时间道具触发时显示）
└── 红框脉冲装饰            # 最后 3 秒触发
```

### 3.2 状态变化

| 状态 | 表现 |
|------|------|
| 正常 | 白字大号数字 |
| 最后 3 秒 | 红色警示 + 红框脉冲 + BGM 变化 |
| 快进 2.0x | 计时器橙红 + "2.0x" 徽标 + 齿轮加速音 |
| 慢放 0.5x | 计时器青蓝 + "0.5x" 徽标 + 低速滴答 |
| 加时 +3s | 绿色 "+3.0s" 飞入计时器 |
| 减时 -3s | 红色 "-3.0s" 切割动画（最低 1 秒） |

### 3.3 规则

- 数值为唯一真值，不显示每人独立时间。
- 快进/慢放互斥，以最后触发覆盖；同类刷新。
- 加时/减时可累计，显示单次增量，不连续刷屏。

## 4. 相机取景 UI（屏幕中央）

### 4.1 定位与结构

屏幕中央，对局全程显示。

```
CameraViewfinder (Control, 居中)
├── PhotoRect (TextureRect)     # PhotoCamera RT（SubViewport.get_texture()）
├── FrameOverlay (TextureRect)  # 取景框贴花：边框/四角/快门装饰（仿相机 2D 图）
├── 可选装饰：
│   ├── FocusCorners           # 对焦四角（决胜时刻变红）
│   └── ShutterIcon            # 快门图标
```

### 4.2 规则

- 取景框**仅标记成像范围**：不碰撞、不加分、不遮挡角色。
- **相机遥控器**：取景框（RT 画面）平滑偏向使用者，2.5 秒后回正，无硬切。不改变舞台，结束后回正。
- **倒计时不进取景框**（交互文档 V1.0 明确：倒计时在顶部中央，取景框只标记成像范围）。

> 注：此前 v1.1 曾设计"倒计时放取景框内"，已按交互文档 V1.0 修正为顶部中央。

## 5. 四角玩家面板（PlayerCornerPanel）

### 5.1 布局（修正）

| 玩家 | 锚点 |
|------|------|
| P1 | 左上 |
| P2 | 右上 |
| P3 | 左下 |
| P4 | 右下 |

### 5.2 面板结构

```
PlayerPanel (PanelContainer)
├── Avatar (TextureRect)         # 颜色 + 形状图标（P1蓝圆/P2橙三角/P3绿方/P4紫菱）
└── InfoVBox
    ├── NameLabel                # "P1"（玩家颜色着色）
    ├── OutfitRow (HBoxContainer) # 服装槽：头 / 身 / 手（3 槽独立）
    └── ItemRow (HBoxContainer)   # 道具槽（当前 1 格，预留扩展）
```

### 5.3 服装槽（3 槽独立，头部/身体/手持）

- 每槽一个图标位，空槽显示**轮廓**。
- 装备即生效；同槽替换时旧图标淡出、新图标弹入，完成后 0.3 秒硬直。
- 无套装进度、无套装效果、无服装专属区域。

### 5.4 道具槽（单槽）

- 当前只持有 1 个；UI 按槽位行设计，未来开放多道具时扩容。
- 使用后图标清空 + 灰闪。

### 5.5 数据与刷新

| 数据 | 来源 | 刷新时机 |
|------|------|----------|
| 玩家颜色/编号/形状 | 匹配流程注入（待定接口） | 开局一次 |
| 服装 | `EventBus.outfit_changed(player_index, slot, item_id)`（新增） | 拾取/替换/卸下 |
| 道具 | `EventBus.item_picked_up` / `item_used`（已有） | 拾取/使用 |

## 6. 世界交互提示（WorldInteraction）

### 6.1 拾取提示

- 邻近可交互物（组件/道具）显示图标。
- **长按 0.8 秒**拾取，显示进度环；移动/被撞/受控则中断，显示红叉。
- **同一玩家只显示一个最近目标**提示。
- 拾取/使用道具、拾取组件时角色头顶飘出图标（见第 8 节拾取气泡）。

### 6.2 表现

```
交互物上方：组件/道具图标 + 拾取进度环（0.8s）
中断：红叉 + 进度清空
```

---

## 7. 角色头顶编号 + 脚底朝向光环

### 7.1 头顶编号

- 角色头顶显示编号（P1~P4）。
- 被遮挡时保留编号描边（世界内提示，不随角色移动）。

### 7.2 脚底朝向光环

- 瓜子型贴地光环，跟随角色移动，指示朝向。
- 实现方式：3D 世界内贴地元素（角色子节点或跟随节点），不限定具体做法，但必须有。

> 方向箭头**不放头顶**，用脚底光环标识朝向。

---

## 8. 头顶拾取气泡（PickupBubble）

- 捡到道具/衣服时，玩家头顶飘出对应图标，持续 2~3 秒（默认 2.5s），向上飘动 + 淡出。
- 图标背景用玩家颜色描边；传说金装加金色光效 + 更大尺寸。
- 连续拾取时旧气泡立即替换。

技术：2D 元素，通过 `main_camera.unproject_position(玩家头顶世界坐标)` 每帧跟随。

---

## 9. 屏幕外方位指示（OffscreenIndicator）

- 玩家处于**主相机**视野外时，屏幕边缘出现小气泡指向其方位。
- 气泡显示玩家图标（颜色+形状+编号），回到视野内即消失。

```gdscript
var p := main_camera.unproject_position(player.global_position)
var on_screen := not main_camera.is_position_behind(player.global_position) \
    and p.x >= 0 and p.x <= viewport_w and p.y >= 0 and p.y <= viewport_h
```

- 出屏（含相机背面）：以屏幕中心为原点归一化方向，气泡 clamp 到屏幕边缘内边距 20px。
- 多玩家出屏去重叠（P0 可先不做）。

## 10. 快门 / 评分 / 冠军演出

### 10.1 快门（S5）

```
0.5x 慢放 → 白闪 → 机械快门 → 定格合照（不含任何 UI 组件）
```

- 保存最终帧为合照，画面中不出现 HUD。
- 白闪 + 快门音效。

### 10.2 评分（S6）

- 照片居中放大。
- 四角玩家 UI 上逐维刷分（入镜程度/站位优势/镜头朝向/清晰度遮挡/服装表现），一下一下刷。
- 任意确认键可加速，不可篡改。
- 无 Pose、无互赞、无投票入口。

### 10.3 冠军（S7）

- 总分排名，冠军在四角 UI 上加皇冠特效 + 图标。
- 称号仅表现，不影响分数。
- 重开 / 返回房间按钮。

## 11. 时间道具反馈（全局倒计时联动）

| 道具 | 效果 | UI 反馈 |
|------|------|---------|
| 快进发条 | 倒计时 2.0x，3 秒 | 计时器橙红 + 2.0x 徽标 |
| 慢放沙漏 | 倒计时 0.5x，3 秒 | 计时器青蓝 + 0.5x 徽标 |
| 加时电池 | +3 秒 | 绿色 +3.0s 飞入 |
| 减时剪刀 | -3 秒（最低 1 秒） | 红色 -3.0s 切割动画 |

时间道具只作用于全场倒计时，不直接限制他人行动。

## 12. 节点结构（集成到关卡场景）

```
HUD (CanvasLayer)
├── TopBar (Control)                       # 顶部中央：倒计时 + 倍率徽标
│   ├── TimerLabel
│   └── RateBadge
├── CameraViewfinder (Control)             # 屏幕中央：RT + 取景框贴花
│   ├── PhotoRect (TextureRect)            # PhotoCamera RT
│   └── FrameOverlay (TextureRect)         # 仿相机 2D 贴花
├── PlayerPanels (Control)
│   ├── P1Panel（左上）/ P2Panel（右上）/ P3Panel（左下）/ P4Panel（右下）
└── Overlay (Control, mouse_filter=IGNORE)
    ├── WorldInteraction                   # 拾取进度环
    ├── PickupBubbles                      # 头顶拾取气泡
    ├── OffscreenArrows                    # 屏幕外方位指示
    └── ShutterFlash (ColorRect)           # 快门白闪（全屏）
```

3D 世界内（非 HUD）：
```
角色子节点：
├── HeadLabel（头顶编号，遮挡保留描边）
└── FootHalo（脚底瓜子型朝向光环）
```

脚本分工：
- `hud.gd`（已有）→ 阶段名 + 倒计时 + 取景框 RT 绑定
- `player_hud.gd`（新增）→ 四角面板 + 气泡 + 出屏指示 + 拾取环

## 13. 信号接口

### 13.1 已有可复用

```gdscript
EventBus.item_picked_up(player_index: int, item: Node)
EventBus.item_used(player_index: int, item: Node)
EventBus.stage_timer_updated(seconds: float)   # 倒计时
EventBus.stage_changed(stage: int)
```

### 13.2 需新增

```gdscript
EventBus.outfit_changed(player_index: int, slot: int, item_id: String)  # 服装槽变化
EventBus.time_effect_applied(effect_type: int, value: float)            # 时间道具（倍率/加减时）
```

### 13.3 需与同事约定

| 接口 | 负责方 |
|------|--------|
| 玩家名/头像/颜色/形状数据 | 流程/匹配同事 |
| 服装当前装备 + outfit_changed | 服装系统同事 |
| 道具/组件图标资源映射（item_id→图标） | 道具/服装同事 |
| 时间道具触发事件 | 道具系统同事 |

## 14. 遮挡优先级（交互文档 V1.0）

```
倒计时 > 设备断开/暂停 > 快门 > 评分 > 玩家角标 > 世界提示
```

同级按距离和交互性去重。

## 15. 可访问性

- 高对比描边。
- 可关闭屏幕闪烁（白闪以淡入替代）。
- 时间事件采用颜色 + 文字 + 图标 + 音效至少两种通道。
